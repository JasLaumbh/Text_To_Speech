# 🗣️ Text-to-Speech Converter

A simple and interactive Text-to-Speech (TTS) web app built using HTML, CSS, and JavaScript. Users can enter text and have it read aloud using the Web Speech API.

---

## 🎯 Features

- 🔊 Converts written text to spoken words
- 🌐 Supports multiple voices and languages (depending on the browser)
- 🎚️ Allows control over pitch and rate
- 🖥️ Clean, responsive user interface
- ⚡ Works entirely in the browser, no backend required

---

## 🛠️ Tech Stack

- **HTML** – structure
- **CSS** – styling
- **JavaScript** – functionality via Web Speech API
